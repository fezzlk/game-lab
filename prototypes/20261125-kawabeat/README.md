# 河ビート（仮）

麻雀 × ループとレイヤー（2026-11-25 提案の案A、2026-11-27 に採用）。

## 面白さの核
**手を欲張って育てるほど音が厚くなるが、拍に遅れると切れず、危険牌を切ると放銃する**（リスクとリターン）。
オーナーの意見「ルールは微妙。一人麻雀をリズミカルに気軽に行う点がよい。牌効率や危険牌判断の練習になる」を受け、
ルールは最小限（字牌なし・鳴きなし・ツモあがりのみ）にして、「1拍で1枚切る」テンポと牌効率・危険牌の判断に絞った。

## 操作
- キーボード：← → で牌を選ぶ、Space / Enter / ↓ で切る、↑ でツモ切り、M でミュート
- タッチ／マウス：切りたい牌をタップ（タップ＝選んで即切る）

## 遊び方・ご褒美と目標
- 1拍ごとに牌が1枚くる（ツモ）。**次の拍が来るまでに1枚切る**。切らないと自動でツモ切りになり、その位置は無音（抜け）でコンボも切れる
- 切った牌は次の拍の位置の「河」に入り、4拍ごとにループで鳴る。萬＝ドラム、筒＝ベース、索＝メロディ（数字で高さが変わる）
- 手の中の面子（順子・刻子）が増えるほど、その色の音が厚くなる（左のメーター）
- 切るたびに「牌効率 ○/×」が出る。向聴数を最小に保つ切り方なら○でコンボが伸び、コンボ倍率で加点が増える。拍の直前（金色の帯）で切るとジャストで加点
- 右上の「危険牌」（赤＝放銃70%、橙＝25%）を切ると、その確率で放銃して失点し、その局が終わる。手の中の危険牌には枠と％が付く。8拍ごとに入れ替わる
- あがる（ツモ）とフルコーラスが鳴り、役の翻数 × 1000点。30回ツモして届かなければ流局。3局の合計点が目標
